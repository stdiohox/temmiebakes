# n8n workflows

These are the production versions of every automation in the demo. The demo simulates them in the browser (`src/lib/engine.ts`). These exports are what would run in n8n, against Supabase, the WhatsApp Cloud API, the Instagram Graph API and Paystack.

They are generated by `node scripts/build-workflows.mjs`. Edit the script, not the JSON.

| File | Automation | Triggers |
|---|---|---|
| `00-error-handler.json` | Logs failures and WhatsApps Koret the failing node and execution link | Error trigger |
| `01-order-intake.json` | Website checkout, cake builder and Tia orders. It normalises the order, finds or creates the customer, prices it from the price book, checks lead time and oven capacity, creates a quoted order, sends a Paystack deposit link on WhatsApp and starts the follow-up | Webhook |
| `02-ai-order-assistant.json` | Tia. Gemini classifies and extracts the order details (Pidgin included), handoff rules run before any reply, Claude replies from the approved price book and knowledge base, a guardrail blocks invented prices or discounts, and the reply goes out on the right channel | Webhooks: Instagram, WhatsApp, website chat |
| `03-quote-follow-up.json` | Nudge 6h after the quote, last call at 24h, then release the kitchen slot | Called by 01 |
| `04-payment-reminders.json` | Paystack webhook with a verified signature marks the deposit or balance paid and confirms on WhatsApp. Daily balance reminders 48h before delivery | Paystack webhook, daily 08:00 |
| `05-order-updates.json` | WhatsApp update when an order moves to baking, ready, out for delivery (rider and ETA) or delivered. Calls 07 an hour after delivery | Supabase database webhook |
| `06-occasion-reminders.json` | Birthday and anniversary reminders 14 days ahead, for opted-in customers only, at most once a year per occasion | Daily 09:30 |
| `07-review-request.json` | Rating request with a 6h wait. 4 or 5 stars get a thank-you and the Google review link. 1 to 3 stars get a Gemini summary, an alert to Koret and a personal holding reply | Called by 05 |
| `08-reorder-nudge.json` | Personal re-order message (Claude, checked) to customers quiet for 45 to 120 days | Mondays 10:00 |
| `09-capacity-guard.json` | Marks days at 90% of oven points as full so Tia and the website offer the next free date | Every 2 hours |
| `10-stock-reorder.json` | Low ingredients become draft purchase orders per supplier. Koret approves on WhatsApp (6h timeout) before the PO is sent | Daily 18:00 |
| `11-academy.json` | Class seat booking with a waitlist when full, Paystack deposit, and the kit list a week before class | Webhook, daily 09:00 |
| `12-corporate-catering.json` | Package priced per guest, Claude proposal from the supplied figures only, validation, email, 3-day follow-up | Webhook |

## Design rules

These follow the n8n-engineer production contract.

- **One model node per AI job.** Gemini 2.0 Flash handles classification and extraction (temperature 0.1). Claude Sonnet handles replies and writing. Both are called through HTTP Request nodes so the exact request is visible.
- **Every AI output is validated in a Code node.** Anomalies are flagged for Koret and never defaulted silently. Prices in Tia's replies must exist in the price book.
- **Payment status changes only on a signed Paystack webhook.**
- **Routes and waits:** every Switch route is distinct, and terminal paths end in a named No-Op. Every Wait and Send-and-Wait has a time limit.
- **Error workflow:** all workflows use `00-error-handler`.

## Setting up

1. **Import the error handler.** Import `00-error-handler.json` first and note its ID. Replace `REPLACE_WITH_00_ERROR_HANDLER_ID` in the other files (Settings → Error workflow).
2. **Import the rest and link them.** Replace `REPLACE_WITH_01_ID`, `REPLACE_WITH_03_ID` and `REPLACE_WITH_07_ID` in the Execute Workflow nodes with the IDs of 01, 03 and 07.
3. **Bind credentials on the canvas.** Every placeholder is named `REPLACE: ...`. You need Supabase, Anthropic, Gemini, Resend, the WhatsApp Cloud API, the Instagram Graph API and Paystack.
4. **Set the n8n variables:**
   - `WA_PHONE_NUMBER_ID`, `IG_BUSINESS_ID`, `OWNER_WHATSAPP`
   - `PAYSTACK_SECRET`, `DAILY_OVEN_POINTS` (20)
   - `TIA_HANDOFF` (the JSON of the handoff rules from the Tia settings page)
   - `GOOGLE_REVIEW_URL`, `STUDIO_ADDRESS`, `NEW_THIS_MONTH`
5. **Allow for Meta app review.** WhatsApp Business (Cloud API) and Instagram messaging need it, which typically takes 1 to 4 weeks. Paystack, the website, the kitchen and the reports can go live first.
